异常关闭五条件（缺一不得关闭，批次保持隔离）： ① 已关联具体 SN 或声明整批受影响；② 有原始判定证据；③ 有责任人 + 临时措施 + 确认根因 + 纠正措施； ④ 有独立复检记录；⑤ 复检通过且质量工程师确认措施有效。

放行断言（逐条，全通过才放行）

batch.status == pending_release
AND latestSample.result == pass          （启用抽样时）
AND openCriticalIncidentCount == 0
AND isolatedSNCount == 0
AND allRequiredEvidencePresent == true
AND allCriticalCAPAVerified == true
AND 每个未关闭异常的复检范围覆盖其影响 SN 集（逐项）

断言在代码中是独立纯函数，每次放行尝试都执行并记录逐条结果。 拦截时界面逐条说明未满足的前提，而不是只给一个笼统的 false。

判定引擎（第 2 段核心纯函数）

judge(inspection, rule_snapshot) → Decision
约束：不读数据库、不取当前时间、不调用随机数、不调用模型
容差公式（闭区间）：
  lower = 标准值 × (1 − 容差%)
  upper = 标准值 × (1 + 容差%)
  lower ≤ 实测值 ≤ upper   （等于上下限均判 Pass）

三重校验顺序：① 基础校验（六项电参数 + 必填不可空）→ ② 功率范围 → ③ 五项参数容差 → ④ Impp 电流分档 → ⑤ 外观结论。任一 Fail 即记录失败证据。
