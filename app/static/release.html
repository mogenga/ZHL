发起放行

放行断言逐条说明

断言是全通过才放行。被拦截时，系统逐条说明未满足的前提（不是笼统的 false）。

  • 批次状态 = 待放行
  • 最新抽样结论 = Pass（启用抽样时）
  • 未关闭严重异常数量 = 0
  • 隔离 SN 数量 = 0
  • 必需证据齐备 = true
  • 严重 CAPA 已验证 = true
  • 复检范围覆盖（逐异常）

批次非 待放行 状态时后端 409；已归档 批次 409（终态）。
